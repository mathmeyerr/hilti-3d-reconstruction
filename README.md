# Large-Scale 3D Reconstruction from Sparse and Noisy Walkthroughs

ETH Zürich 3D Vision Project in collaboration with Hilti.

## Overview

This project investigates large-scale 3D reconstruction of active construction sites from sparse and noisy 360° walkthrough videos. We adapted the DA3 feed-forward reconstruction pipeline to industrial construction-site data using:

* IMU-guided panorama decomposition
* Dynamic-object masking with Grounded-SAM-2
* Loop-closure refinement
* Construction-site-specific filtering and evaluation

The system was evaluated on 30 construction-site sequences from the Hilti × Trimble Challenge dataset.
